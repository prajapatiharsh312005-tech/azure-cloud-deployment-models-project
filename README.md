# Azure Cloud Deployment Models

## Project Overview
This project compares three Microsoft Azure deployment models by examining how applications are deployed, managed, secured, and scaled.

## Objectives
- Understand Infrastructure as a Service (IaaS), Platform as a Service (PaaS), and serverless computing.
- Compare Azure Virtual Machines, Azure App Service, and Azure Functions.
- Understand infrastructure control, maintenance, scalability, security, and cost factors.
- Document the architecture and deployment process for each model.

## Deployment Models

| Model | Azure Service | Management |
|---|---|---|
| IaaS | Azure Virtual Machines | More control; user manages the OS and application |
| PaaS | Azure App Service | Azure manages the underlying infrastructure |
| Serverless | Azure Functions | Run code in response to events or requests |

## Cost and Safety
The existing Azure App Service deployment will be used as a reference. Additional resources will only be created after checking pricing and available subscription options.
